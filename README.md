# Sentiment Analysis using Machine Learning

## Project Overview

This project demonstrates sentiment analysis using Natural Language Processing (NLP) and Machine Learning.

The model classifies text reviews into three sentiment categories:
- Positive
- Negative
- Neutral

## Technologies Used

- Python
- NumPy
- Pandas
- Scikit-learn
- Natural Language Processing (NLP)
- TF-IDF
- Logistic Regression
- Google Colab

## Project Workflow

1. Dataset Loading
2. Data Exploration
3. Text Cleaning
4. Sentiment Label Encoding
5. TF-IDF Feature Extraction
6. Train-Test Split
7. Logistic Regression Model Training
8. Model Evaluation
9. Confusion Matrix
10. Classification Report
11. New Review Prediction
12. Model Saving

## Dataset

The dataset contains 30 text reviews:
- Positive: 10
- Negative: 10
- Neutral: 10

## Model Performance

Test Accuracy: **50%**

The test set contains 6 samples, so this accuracy is intended as a demonstration of the machine-learning workflow.

## Sample Predictions

| Review | Predicted Sentiment |
|---|---|
| I really love this product | Positive |
| The product is okay and works as expected | Neutral |
| I am very disappointed with this product | Positive |

## Conclusion

This project demonstrates an end-to-end sentiment analysis workflow using NLP and Logistic Regression, from text preprocessing and feature extraction to model evaluation and prediction.
